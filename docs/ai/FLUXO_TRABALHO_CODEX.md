# Fluxo de trabalho Codex

```text
baseline integrado
  ↓
reconciliação documental
  ↓
seleção de item
  ↓
prompt bounded
  ↓
PR
  ↓
review/merge pelo usuário
  ↓
reconciliação
  ↓
próxima onda segura
```

Tipos separados:

- análise;
- decisão;
- implementação;
- bug fix;
- teste;
- reconciliação;
- ambiente.

Uma onda oficial possui exatamente cinco slots independentes.
