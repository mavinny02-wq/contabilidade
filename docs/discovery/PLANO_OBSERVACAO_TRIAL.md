# Plano de observação do trial

Para cada tela ou fluxo observado na Veri:

- objetivo;
- pré-condições;
- dados obrigatórios;
- campos e filtros;
- estados;
- ações e ações em lote;
- permissões aparentes;
- mensagens de erro;
- estados vazios;
- comportamento após refresh;
- dependência externa;
- evidência visual autorizada;
- dúvida ainda aberta.

Classificação:

- `JA_PLANEJADO`;
- `ADAPTAR`;
- `NOVO_REQUISITO_CANDIDATO`;
- `NAO_NECESSARIO_INTERNO`;
- `MELHOR_QUE_NOSSA_ABORDAGEM`;
- `INFERENCIA_NAO_CONFIRMADA`.
