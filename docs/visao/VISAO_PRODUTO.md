# Visão do produto

Criar uma plataforma interna única para centralizar operações fiscais e contábeis da empresa.

## Não é SaaS
Ficam fora inicialmente: vendas, checkout, assinatura, planos, trial comercial, white-label, CRM, múltiplos clientes e onboarding comercial.

## Sequência
`Fundação → Common → Empresas → Automação → Certidões → demais módulos`.
