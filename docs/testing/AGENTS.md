# Regras de agentes — testes e evidências

Este arquivo especializa `docs/AGENTS.md` para `docs/testing/**`.

- Validação não autoriza mudança de produção.
- Primeiro estabeleça baseline, ambiente, comando, resultado e autoridade atual.
- Classifique toda falha antes de selecionar correção.
- Reutilize evidência válida; não repita owner não afetado.
- Compile/build não é prova de runtime, banco, browser, acessibilidade ou provider.
- Prova Cloud e prova Windows local são categorias distintas.
- Real external E2E e provider pago são proibidos sem autorização explícita.
- Todo resultado, inclusive blocker/no-op, é persistido em Markdown.
