# Orquestração do Contabilidade

Este pacote é a autoridade operacional da orquestração v2.

Comece por:

1. `CONTABILIDADE_CURRENT_STATE.md`;
2. `CONTABILIDADE_WAVE_ORCHESTRATION_V2.md`;
3. `CONTABILIDADE_EXECUTION_OWNER_MATRIX.md`;
4. ledger/shard exato necessário.

Pastas futuras de ondas devem usar:

```text
waves/prepared/
waves/released/
waves/consumed/
waves/superseded/
```

Somente `waves/released/` pode conter launchers executáveis.
