# STR-OWN-001 — CODEOWNERS e hotspots

**Objetivo:** transformar a matriz de owner em enforcement/review sem inventar identidades.

## Escopo

- mapear owners técnicos existentes;
- definir CODEOWNERS somente para usuários/times confirmados;
- manter hotspots serializados;
- documentar fallback quando existe um único maintainer;
- alinhar branch protection.

## Aceite

Owners reais, nenhuma referência inválida e review requerido nos paths críticos aplicáveis.
