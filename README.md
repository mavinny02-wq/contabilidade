# Contabilidade

Plataforma interna de operações fiscais e contábeis, desenvolvida em módulos e em português.

## Estratégia

1. Fundação técnica.
2. Common reutilizável.
3. Empresas/CNPJs.
4. Automação e intervenção humana.
5. Centro de Certidões.
6. Demais verticais conforme discovery.

Todo texto visível usa chaves i18n, mesmo existindo apenas `pt-BR` inicialmente.
