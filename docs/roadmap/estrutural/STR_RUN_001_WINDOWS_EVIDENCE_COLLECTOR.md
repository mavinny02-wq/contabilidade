# STR-RUN-001 — coletor de evidência Windows

**Objetivo:** produzir evidência machine-readable do runtime local sem segredo/provider.

## Escopo

- PowerShell/BAT seguro;
- SHA, versões de ferramentas, compose config, health, Flyway, endpoints técnicos e smoke autorizado;
- JSON + Markdown;
- redaction;
- exit codes;
- nenhuma chamada fiscal externa/paga.

## Aceite

Artefato executável manualmente, schema validado no Cloud e reconciliação por SHA.
